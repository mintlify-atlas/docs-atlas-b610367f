The Library Reservation System is a full-featured backend service for managing library reading rooms, seats, and reservations. Built on Spring Boot 2.6 with Spring Security and JWT authentication, it gives administrators full control over rooms, seats, books, and users — while giving patrons a seamless flow from seat reservation through face-verified check-in to check-out.

## Key Features

<CardGroup cols={2}>
  <Card title="Seat Reservations" icon="chair" href="/features/reservations">
    Reserve seats, check in with face recognition, mark temporary absence, and check out — all with real-time seat status updates.
  </Card>
  <Card title="Reading Room Management" icon="building-columns" href="/features/rooms-and-seats">
    Create and manage reading rooms and their seats. Track availability with three seat states: available, temporarily absent, or occupied.
  </Card>
  <Card title="Face Recognition" icon="face-viewfinder" href="/features/face-recognition">
    Biometric check-in and check-out powered by the Baidu AI Face Match API, compared against the user's registered avatar.
  </Card>
  <Card title="Violation Reporting" icon="triangle-exclamation" href="/features/violations">
    Users can report rule violations. Administrators process reports and deduct credit scores from offending patrons.
  </Card>
  <Card title="JWT Authentication" icon="lock" href="/configuration/security">
    RSA-encrypted password submission, arithmetic CAPTCHA login, JWT tokens with auto-renewal, and Redis-backed online session management.
  </Card>
  <Card title="Role-Based Access" icon="shield-halved" href="/administration/users-and-roles">
    Fine-grained permission checks using Spring Security's `@PreAuthorize` with a custom `@el.check()` expression evaluator.
  </Card>
</CardGroup>

## Getting Started

<Steps>
  <Step title="Clone and configure">
    Clone the repository, create a MySQL database named `library-face`, and configure your database credentials in `application-dev.yml`.
  </Step>
  <Step title="Start Redis">
    The system requires a running Redis instance on `localhost:6379` (configurable via environment variables).
  </Step>
  <Step title="Build and run">
    Build with Maven and start the Spring Boot application on port `8000`.
  </Step>
  <Step title="Authenticate">
    Obtain a CAPTCHA from `GET /auth/code`, then POST your credentials to `POST /auth/login` to receive a JWT Bearer token.
  </Step>
</Steps>

<Note>
  The default server port is **8000**. All library API endpoints are prefixed with `/api/` and require a valid `Authorization: Bearer <token>` header unless otherwise noted.
</Note>
